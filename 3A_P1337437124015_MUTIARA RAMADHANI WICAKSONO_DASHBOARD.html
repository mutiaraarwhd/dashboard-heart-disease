Halaman 1

Catatan metodologis: dashboard ini melakukan analisis deskriptif dan tidak menetapkan diagnosis atau risiko individual. Variabel seperti sex, cp, restecg, slope, thal, dan target ditampilkan sebagai kode kategori sebagaimana tersimpan di CSV. Tidak ditemukan nilai kosong pada dataset bawaan. Grafik menggunakan Chart.js melalui CDN sehingga koneksi internet diperlukan untuk memuat library grafik; tabel, filter, KPI, dan ekspor tetap berbasis JavaScript di halaman ini.
